What is Logistic Regression?

Logistic regression estimates the probability that an example belongs to class 1. First, it calculates a linear score, \(z = mx + b\). Then it transforms that score into a probability between 0 and 1 with the sigmoid function: \( \hat{p} = \sigma(z) = \frac{1}{1 + e^{-z}} \).

Is the prediction good?

The curve gives us a probability, but our data points have actual labels: 0 or 1. We need a way to compare the two. Let’s take a look at classification error and loss!

Classification Error

For this demo, a probability of 0.5 or higher is counted as class 1. Anything below 0.5 is class 0. Classification error is the fraction of examples the model puts in the wrong class, shown as a percentage above.

This is easy to understand, but it only says whether a prediction was right or wrong. It doesn’t tell us how confident the model was. A prediction of 0.51 and a prediction of 0.99 are both counted as class 1.

Binary Cross-Entropy Loss

Binary cross-entropy looks at the probability itself, not just the final class. For all \(n\) examples, we calculate: \(\text{BCE} = -\frac{1}{n}\sum_{i=1}^{n}\left[y_i\log(\hat{p}_i) + (1-y_i)\log(1-\hat{p}_i)\right]\).

Here, \(y_i\) is the actual class (0 or 1), and \(\hat{p}_i\) is the probability our model gives to class 1. If the true class is 1, a low predicted probability gets a large penalty. If the true class is 0, a high probability gets a large penalty. The more confidently wrong the model is, the larger the loss. Ouch! The script keeps probabilities just above 0 and just below 1 before taking the logarithm, so it never tries to calculate log(0).

The loss shown above is the average across all the examples. A smaller loss means the probabilities fit these labels better. Unlike classification error, the loss changes as the probabilities change, which makes it useful when training a model to improve its predictions.
