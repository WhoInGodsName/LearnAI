What is Logistic Regression?

Logistic regression estimates the probability that an example belongs to a class. It transforms a linear score into a value between 0 and 1 using the sigmoid function: \(p = \frac{1}{1 + e^{\sigma}}\) where \( \sigma = -(mx+b)\).
