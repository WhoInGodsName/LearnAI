What is Linear Regression?

Linear regression is the first pit stop we will be taking on this Machine Learning journey. This supervised Machine Learning model helps us predict an output (the dependent variable) from one or more inputs. For this example, the model is \( y = \beta_1 x_1 + \beta_0 + \epsilon \). Here, \( \beta_1 \) is the slope, \( x_1 \) is the input, and \( \beta_0 \) is the y-intercept. The \( \epsilon \) term represents variation the model does not explain; it is not the loss score.

Sum of Squared Residuals (SSE): Mean Squared Error (MSE):

Residuals

A residual is the difference between the observed y-value and the value predicted by our model: \(r_i = y_i - \hat{y}_i\). On the graph, it is the vertical gap from a data point to the line.

Residual Distance

Enabling the first checkbox in the demo above shows that gap for each data point. A smaller residual magnitude means that point is closer to the line. The sign also tells us which side of the line the point is on: positive above, negative below.

If we simply add the signed residuals, positive and negative values can cancel each other out. That could make a poorly fitting line look better than it is, so we square each residual before combining them.

Squared Residuals

Squaring a residual gives \(r_i^2 = (y_i - \hat{y}_i)^2\). This removes the negative sign, and makes larger residuals count more heavily. Enable the second checkbox to see a square for each residual: the bigger the gap, the larger its area and its contribution to the error. This is a squared residual; \(R^2\) is a different measure of model fit.

Mean Squared Error (MSE)

Now that we have squared the residuals, we can add them together and find their average. This is the Mean Squared Error: \( \text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2 \). The MSE gives us one number to describe how far the model’s predictions are from the observed values. A smaller MSE means the line fits these data points more closely.
